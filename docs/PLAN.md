# План разработки

Краткая карта этапов. Подробности каждой задачи (шаги, файлы, критерии готовности, что учитывать) — в [HANDOFF.md](HANDOFF.md), раздел 10.

## Что требует задание

Интерактивная игра, в которой участник проектирует космическую миссию целиком: цель → аппарат → приборы → орбита → ракета, с ограничениями по бюджету, массе, энергии, связи, данным и сроку работы. Главная мысль: в миссии всё связано, и идеального решения нет. Сильное решение включает понятный интерфейс, управление ресурсами, симуляцию с оценкой, игру в одиночку и командой с ролями, объяснение причин результата. Подробная сверка с заданием — HANDOFF, раздел 1.

## Правила баланса

Тесты фиксируют три эталонных проекта для каждой миссии — на базовых, стандартных и профессиональных приборах — и запускают каждый 200 раз. Стандартный должен проходить комиссию без обязательных замечаний, оставлять 3–30% бюджета и побеждать в 60–98% полётов. Базовый стоит меньше 80% бюджета и даёт частичный успех. Профессиональный даёт больше науки за больше денег и помещается в бюджет среднего уровня; по очкам он в пределах 10% от стандартного. Стандартный проект должен проходить комиссию на всех трёх уровнях сложности. Меняя числа, запускайте `npm test`.
